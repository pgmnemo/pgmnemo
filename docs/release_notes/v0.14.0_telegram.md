**Память для кодинг-агентов — в вашем Postgres**

Агент забывает всё между сессиями. Самое частое решение — складывать заметки файлами в репозиторий. Работает, пока агент один: как только их несколько и пишут они одновременно, начинаются конфликты, а искать в куче markdown нечем.

Вышел **pgmnemo-mcp 0.14.0** — доступ к памяти в Postgres из Claude Code, Codex и Gemini через один MCP-сервер.

Что появилось:

• `pip install pgmnemo-mcp`, затем `pgmnemo init` — определяет ваш CLI и прописывает конфиг сам
• факты, события и связи пишутся раздельными типами, а поиск умеет по типу фильтровать
• хуки сессии: подтянуть контекст на старте, записать итог в конце
• `pgmnemo export` — выгрузка памяти в markdown, чтобы прочитать и поправить глазами

Хранилище одно, модели разные — контекст переносится между ними.

Под капотом остаётся обычный Postgres: расширение ставится через `CREATE EXTENSION`, данные никуда не уезжают, бэкапы и права — ваши штатные.
