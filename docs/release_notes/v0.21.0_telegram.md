**pgmnemo 0.21.0** — штатный pg_dump теперь сохраняет память

Патч надёжности, без новых функций. Исправлена тихая потеря данных: во всех версиях до 0.21.0 `pg_dump` выгружал расширение pgmnemo без единой строки корпуса. Схема и функции в дампе были, уроки, рёбра графа и журнал загрузки — нет. Восстановление из такого бэкапа давало рабочее расширение с пустой памятью.

**Что исправлено.** Таблицы `agent_lesson`, `mem_edge`, `memory_ingest_log` и их счётчики id зарегистрированы через `pg_extension_config_dump()`. Теперь обычный `pg_dump` / `pg_restore` переносит корпус целиком, а новые записи после восстановления получают id без коллизий. Таблица переходов состояний (`agent_lesson_state_transition`) намеренно не выгружается — её заново создаёт `CREATE EXTENSION`, иначе восстановление упёрлось бы в дубликаты ключей.

**Как проверено.** Не только по каталогу: настоящий цикл `pg_dump -Fc` → `pg_restore` в пустую базу, для свежей установки и для обновления с 0.20.0. Сверяются число строк и md5 всех трёх таблиц, непрерывность последовательностей, отсутствие дублей и то, что recall находит восстановленные уроки. Контроль: дамп версии 0.20.0 не содержит ни одной строки данных; если убрать регистрацию — тест падает.

**Что важно знать.**
— Бэкапы, снятые до 0.21.0, строк pgmnemo не содержат. Не удаляйте исходную базу, пока нет дампа 0.21.0: проверьте `pg_restore -l dump | grep 'TABLE DATA pgmnemo'`.
— Сначала обновитесь, потом делайте дамп: `ALTER EXTENSION pgmnemo UPDATE TO '0.21.0'` меняет только метаданные, блокировок таблиц нет.
— На 0.20.0 и старше обходной путь `pg_dump -t pgmnemo.agent_lesson` не работает (проверено — в выводе нет строк). Если обновиться пока нельзя, выгружайте через `\copy`.

**Совместимость.** Схема, функции, индексы и GUC не менялись; каталог свежей 0.21.0 побайтово совпадает с 0.20.0 (50 функций по md5, 107 столбцов, 39 индексов). 300 запросов `recall_hybrid` вернули одинаковые списки id. Значения GUC по умолчанию не менялись. Заявлений о качестве поиска нет — оно не затронуто.

Требуется PostgreSQL 17 и pgvector 0.7–0.8 (границы теперь явно указаны в META.json).

Обновление: `ALTER EXTENSION pgmnemo UPDATE TO '0.21.0'`. Пути с 0.0.1, 0.8.0, 0.15.1, 0.19.1 и 0.20.0 проверены; обновлённая установка совпадает со свежей (G-UPGRADE-PARITY).
