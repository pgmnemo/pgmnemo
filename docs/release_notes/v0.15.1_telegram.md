**pgmnemo 0.15.1 — поиск по ситуации теперь уважает настройку доверия**

В 0.15.0 мы отгрузили поиск прошлых случаев по классу ситуации и честно написали прямо в описании функции, что настройку «показывать только проверенные записи» она пока не читает. Обещали доделать — доделали.

Теперь `recall_situation()` читает `pgmnemo.include_unverified` так же, как остальные функции поиска.

**Важно для тех, кто уже на 0.15.0.** Поведение по умолчанию изменилось: раньше функция возвращала все записи, теперь — только проверенные. Если в вашей базе много непроверенных записей, выдача станет меньше. Вернуть прежнее: `SET pgmnemo.include_unverified = 'on';`

Мы вынесли это первым пунктом в CHANGELOG, а не спрятали под описание фичи: тихо просевшая выдача — худший вид поломки.

**И отдельно — чиним то, что сломали не мы.** Вышла версия библиотеки `mcp` 2.0, в которой удалён модуль, на который опирался наш MCP-сервер. Из-за нестрогого ограничения версий `pip install pgmnemo-mcp` какое-то время ставил неработающий пакет. Исправлено в `pgmnemo-mcp 0.15.2` — зависимость закреплена, установка проверена начисто. Если ставили на днях и получили ошибку импорта: `pip install -U pgmnemo-mcp`.

Обновление расширения: `ALTER EXTENSION pgmnemo UPDATE TO '0.15.1';`
