**pgmnemo 0.18.0**

Два изменения. Одно про скорость, одно про качество памяти.

---

**Поиск по памяти перестал писать в базу при каждом чтении**

Каждый раз, когда агент вызывал поиск урока, база не просто читала — она тут же записывала, что урок был использован. Эта запись и была источником проблем: в моменты, когда другие процессы обновляли те же данные или перестраивали индексы, поиск останавливался и ждал. Иногда больше 9 минут.

Теперь поиск только читает. На тихой системе это 3–4 мс вместо 44 мс (замер на 3600 уроков, одно соединение). Под нагрузкой больше не блокируется совсем — конкурирующие записи на него не влияют.

**Оговорка к числу.** 44 мс → 3 мс измерено на конкретной машине в момент замера до обновления; повторить «до» уже нельзя. Результат «после» воспроизводим: `benchmarks/gate/v0.18.0.json` содержит скрипт и ожидаемый диапазон.

---

**Ломающее изменение — прочитайте, если используете `mark_stale()` или историю обращений к урокам**

Раньше при каждом поиске автоматически обновлялось поле «когда урок последний раз использовали». Теперь это не происходит — поиск стал чистым чтением.

Если вы используете `mark_stale()` для чистки базы (она ориентируется на то, когда урок последний раз встречался в выдаче) — добавьте вызов явно:

```sql
SELECT pgmnemo.mark_recalled(
    ARRAY(SELECT lesson_id FROM pgmnemo.recall_hybrid($1::vector(1024), $2, 10))
);
```

Если не используете `mark_stale()` и история обращений вам не нужна — ничего делать не нужно, поиск работает быстрее.

---

**Черновики, которые реально сработали, теперь сами выходят из черновиков**

74% уроков в живом корпусе застряли в статусе «черновик» навсегда — потому что система не знала, как решить, что черновик подтверждён. Теперь знает: если агент использовал урок и зафиксировал успех три раза — урок автоматически становится «подтверждённым».

Порог три выбран по данным корпуса, а не с потолка: при трёх успехах и нуле неудач байесовское доверие к уроку ≥ 0.80.

Если вы хотите, чтобы какой-то черновик остался черновиком несмотря ни на что:

```sql
UPDATE pgmnemo.agent_lesson
SET metadata = metadata || '{"_auto_promote_exempt": true}'::jsonb
WHERE id = <ваш_id>;
```

Чтобы вернуть урок в черновик вручную:

```sql
SELECT pgmnemo.transition_lesson(<id>, 'draft');
```
