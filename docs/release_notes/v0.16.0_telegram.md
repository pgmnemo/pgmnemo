**pgmnemo 0.16.0 — память теперь отвечает на вопрос «что мы знаем про X»**

До этой версии из памяти можно было достать похожие уроки по смыслу текста. Нельзя было спросить иначе: покажи всё, что накопилось про конкретный класс сбоя, про конкретную модель, про конкретный файл.

Теперь можно.

При записи урока `pgmnemo` сам вытаскивает из его текста ключи сущностей — классы сбоев, идентификаторы моделей, пути к исходникам, имена таблиц и функций. Никаких обращений к языковой модели: детерминированные правила по форме, всё внутри Postgres. Индекс сущностей наполняется сам собой, пока вы просто пишете уроки.

Читается одним вызовом:

`SELECT * FROM pgmnemo.recall_entity('failure:INFRA_FAILURE', 20);`

На нашем корпусе из 5 910 уроков это дало 972 разных ключа, в среднем по два урока на ключ, 332 ключа с тремя и более. Запрос про класс сбоя возвращает срез, который обычным поиском не собрать.

**Чего мы сознательно не делаем.** Извлекатель не создаёт ключ на проект и пропускает пути одноразовых отчётов: и то и другое давало почти сплошные одиночки — записи в индексе, которые никто никогда не спросит. Индекс, набитый мусором, хуже отсутствующего.

Обновление: `ALTER EXTENSION pgmnemo UPDATE TO '0.16.0';`
